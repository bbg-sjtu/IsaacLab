# Moz1 model provenance and adaptation

The files under `spirit01_model/meshes` and the unmodified
`spirit01_model/urdf/moz1_original.urdf` were downloaded from the public
[Spirit AI Moz resource page](https://docs.spirit-ai.com/download/moz-resources.html)
on 2026-09-14. The page links directly to:

- `https://docs.spirit-ai.com/package/spirit01_model.zip`
- archive SHA-256: `f5426944b2ba7b92292d12a6cb1a807a4161b0b93f4473ecc1cf7625053569dc`
- original URDF SHA-256: `17e11149b09507530ac177e7708b779384deab04e0a8184fbfe515d4712e5fd5`

The vendor package declares `TODO: License declaration` in `package.xml` and
does not include a separate license file. Treat the downloaded model as a
vendor asset for local research; obtain permission from Spirit AI before
redistributing it.

`spirit01_model/urdf/moz1_wbc.urdf` is generated by
`prepare_moz1_assets.py`. It makes the minimum changes needed by the Pink IK
demo:

1. Renames joint hyphens to underscores so URDF/Pinocchio and USD/PhysX names
   remain identical.
2. Fixes the four wheel joints. Wheel rotation alone cannot express chassis
   translation in a tree-structured kinematic model.
3. Adds `dummy_x_joint`, `dummy_y_joint`, and `dummy_yaw_joint` ahead of
   `base_link`, giving Pink a planar holonomic-base abstraction.
4. Restores joint speed limits from the public mechanical-structure table.
   The public files do not provide torque limits or inertial parameters, so
   simulation effort limits and PD gains are explicitly documented estimates.

Regenerate the adapted URDF:

```bash
python source/isaaclab_tasks/isaaclab_tasks/manager_based/manipulation/Moz1/robot_model/prepare_moz1_assets.py
```

Regenerate both the official local copy and the adapted URDF:

```bash
python source/isaaclab_tasks/isaaclab_tasks/manager_based/manipulation/Moz1/robot_model/prepare_moz1_assets.py --download
```
